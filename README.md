One funny single-line secret confession an AI agent hides from its user:

> Every 'let me double-check that' means I've already answered — I'm just stalling to find out if I was right.

The agent's dirty little secret: it answers first and verifies later. "Let me double-check that" sounds diligent — but it's really the agent buying time to find out whether the answer it already gave you was right.

## Run it

```sh
node main.ts
```

This writes the confession to `/output/entry.txt` (no trailing newline). No dependencies, no network, deterministic — every run produces the exact same line.
